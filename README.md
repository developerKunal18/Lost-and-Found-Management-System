# Lost and Found Management System

A simple console-based application developed using Python
to manage lost and found items.

## Features

- Report lost items.
- Report found items.
- View all reported items.
- Search by item name or location.
- Update item status.
- Delete item records.
- Generate summary reports.
- Store records using JSON.

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries

## Installation

1. Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

```bash
Lost_and_Found_System
```

3. Run the application.

```bash
python main.py
```

## How to Use

1. Select Report Lost or Found Item.
2. Enter item details.
3. View or search reported items.
4. Update the status when an item is returned.
5. View reports to check the overall records.

## Storage

All item records are stored in:

`data/items.json`
